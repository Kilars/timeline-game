# User stories

Tags: **V1** is in the first build. **Later** is parked in `IDEAS.md` until Lars approves it.

## Player

| # | Story | Tag |
|---|---|---|
| P1 | As a player I open the link on my phone and start a game with the history deck in two taps, with no login. | V1 |
| P2 | As a player I see the title of a drawn card, tap the gap on the timeline where I think it belongs, and confirm to reveal the date. | V1 |
| P3 | As a player, after a correct placement I choose between drawing another card and locking in what I have gained this turn. | V1 |
| P4 | As a player, when I miss I see the correct date and which cards I lost, so I learn something from it. | V1 |
| P5 | As a player I see how many turns I have used and how many cards I need, at all times. | V1 |
| P6 | As a player I see my score when I reach the target, my best score so far, and can play again with the same settings. | V1 |
| P7 | As a player I change the target from 10 to another number. | V1 |
| P8 | As a player I tick which decks to play with and set how large a share of the cards are personal. | V1 |
| P9 | As a player I narrow the history deck by category, period and difficulty. | Later |
| P10 | As a player I type a code I was given and the family deck appears on my phone, and stays there. | V1 |
| P11 | As a player I am never unfairly marked wrong when two cards share a year. | V1 |
| P12 | As a player I switch judging from year to exact date for a harder game with personal cards. | V1 |
| P13 | As a player I get cards I have not seen recently before cards I already know. | Later |
| P14 | As players we take turns on one phone, first to the target wins. | Later |
| P15 | As a player I install the game on my home screen. | Later |

## Admin (holder of an edit code)

| # | Story | Tag |
|---|---|---|
| A1 | As an admin I type my edit code and get an editor for my decks. | V1 |
| A2 | As an admin I add a personal card with a title, a date as precise as I know it, and an optional reveal line. | V1 |
| A3 | As an admin I correct or delete a card, including a history card with a wrong date. | V1 |
| A4 | As an admin I see all cards in a deck sorted by date, so I spot gaps and duplicates. | V1 |
| A5 | As an admin I add many cards at once by pasting a list. | Later |
| A6 | As an admin I add a photo to a personal card. | Later |

## Owner (Lars)

| # | Story | Tag |
|---|---|---|
| O1 | As the owner I create a deck and choose whether it is public or private. | V1 |
| O2 | As the owner I create, replace and revoke play and edit codes for a set of decks. | V1 |
| O3 | As the owner I keep decks that nobody else can see or even know exist. | V1 |
| O4 | As the owner I reach code entry through a hidden gesture, so the app looks like a plain history game to everyone else. | V1 |
| O5 | As the owner I rebuild or extend the history deck by running one script. | V1 |
| O6 | As the owner I know that no personal card is ever in the public repo or the public site files. | V1 |
