# Tidslinje

A timeline card game. Static client on GitHub Pages, private database behind a small API.

Before doing anything, read `docs/STATE.md` (current state and next task) and `docs/WORKFLOW.md` (how work is done here).
The spec is `docs/SPEC.md`; decisions are in `docs/adr/`.

When Lars says "go", run the build loop in `docs/WORKFLOW.md`.

Personal cards never go in the repo, in fixtures or in screenshots.
